# Inter

`inter-latin.woff2` is the Inter Latin font used by the Spatius marketing
site. The same unmodified font asset is bundled locally so this starter
shares its typography without requesting fonts from a third-party CDN.

Upstream: [The Inter Project](https://github.com/rsms/inter).
